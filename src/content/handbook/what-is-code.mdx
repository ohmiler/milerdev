## โค้ดคือสูตรอาหารที่เคร่งมาก

ลองนึกถึงสูตรทำไข่เจียว ตอกไข่ใส่ชาม ใส่น้ำปลา ตีให้เข้ากัน ตั้งกระทะ เทน้ำมัน แล้วจึงเทไข่ลงไป คนอ่านสูตรเข้าใจได้ แม้สูตรจะเขียนไม่ครบ เช่น ไม่ได้บอกว่าต้องเปิดเตา เพราะคนเดาเองได้

คอมพิวเตอร์เดาไม่ได้ ถ้าสูตรไม่ได้บอกให้เปิดเตา มันจะยืนรอให้ไข่สุกบนกระทะเย็น ๆ ไปตลอด โค้ดจึงต้องบอกทุกขั้นให้ครบ ตามลำดับ และเขียนให้ตรงตามกฎของภาษา

## ลองอ่านโค้ดบรรทัดแรก

นี่คือโค้ดภาษา JavaScript สองบรรทัด JavaScript เป็นภาษาที่ทำงานในเบราว์เซอร์ได้ทันที จึงเหมาะกับการเริ่มต้น

```js
let learner = "มิน";
console.log("สวัสดี " + learner);
```

- บรรทัดแรกสร้าง **ตัวแปร** ชื่อ `learner` และเก็บข้อความ "มิน" ไว้ ตัวแปรเหมือนกล่องที่มีป้ายชื่อ เอาไว้ใส่ข้อมูลเพื่อใช้ทีหลัง
- บรรทัดที่สองสั่งให้แสดงข้อความ "สวัสดี " ต่อด้วยสิ่งที่อยู่ในกล่อง `learner` ผลที่ได้คือ "สวัสดี มิน"

ข้อความที่อยู่ในเครื่องหมายคำพูด เรียกว่า string ส่วนเครื่องหมาย `;` ท้ายบรรทัดบอกว่าคำสั่งจบแล้ว

## 4 แนวคิดที่เจอในทุกภาษา

| แนวคิด | หมายถึง | ตัวอย่างในชีวิตจริง |
| --- | --- | --- |
| ข้อมูลและตัวแปร | สิ่งที่โปรแกรมจำไว้ใช้ | ชื่อลูกค้า ราคาสินค้า |
| คำสั่งตามลำดับ | ทำทีละบรรทัด จากบนลงล่าง | ทำตามสูตรทีละขั้น |
| เงื่อนไข | ถ้าเป็นแบบนี้ ให้ทำอย่างหนึ่ง ไม่ใช่ก็ทำอีกอย่าง | ถ้าฝนตก ให้พกร่ม |
| การทำซ้ำ | ทำคำสั่งเดิมหลายรอบ | ส่งอีเมลหาลูกค้าทุกคน |

ลองดูเงื่อนไขกับการทำซ้ำในโค้ดจริง

```js
let score = 72;

if (score >= 50) {
  console.log("ผ่าน");
} else {
  console.log("ไม่ผ่าน");
}

for (let round = 1; round <= 3; round++) {
  console.log("รอบที่ " + round);
}
```

- `if` ตรวจว่าคะแนนตั้งแต่ 50 ขึ้นไปไหม ถ้าใช่แสดง "ผ่าน" ถ้าไม่ใช่ไปทำในส่วน `else` แสดง "ไม่ผ่าน" คะแนนคือ 72 จึงเห็นคำว่า "ผ่าน"
- `for` นับ `round` ตั้งแต่ 1 ถึง 3 และแสดงข้อความทุกรอบ จึงเห็น "รอบที่ 1" "รอบที่ 2" และ "รอบที่ 3"

## คอมพิวเตอร์ไม่เดา และ error คือเบาะแส

ลองพิมพ์ผิดดูสักตัว เช่น เขียน `consol.log` แทน `console.log` Console จะแสดงข้อความสีแดงประมาณนี้

```text
Uncaught ReferenceError: consol is not defined
```

ข้อความนี้ไม่ได้แปลว่าคอมพิวเตอร์พัง มันกำลังบอกว่าเจอคำว่า `consol` ที่ไม่รู้จัก error คือเบาะแสว่าผิดที่ไหน ฝึกอ่านมันทุกครั้ง และเวลาขอให้ AI ช่วย ให้แนบข้อความ error ไปด้วยเสมอ

## ข้อผิดพลาดที่พบบ่อย

1. **วางโค้ดที่ไม่รู้ที่มาลงใน Console** อาจถูกขโมยบัญชีได้ วางเฉพาะโค้ดที่เข้าใจ
2. **ลืมเครื่องหมายคำพูดหรือวงเล็บ** ภาษาโปรแกรมเคร่งเรื่องนี้มาก เปิดแล้วต้องปิดเสมอ
3. **ตกใจเมื่อเห็น error** error เป็นเรื่องปกติของทุกคน แม้แต่คนที่เขียนโค้ดมาหลายสิบปี
