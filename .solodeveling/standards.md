# Standards

- Follow `AGENTS.md` for repository safety, coding style, and verification.
- Follow `milerdev-color-palette.md` for semantic colors and light-default behavior.
- Use `npm` scripts from `package.json`.
- Definition of done: scoped acceptance criteria are met, focused tests pass, lint/build are run when practical, responsive UI is inspected when browser capability is available, and `git diff --check` passes.
