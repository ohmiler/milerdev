name: grill-with-docs
description: A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.
disable-model-invocation: true
---

Sharpen the proposed plan by identifying unresolved goals, constraints, failure cases, and consequential tradeoffs. Read relevant existing domain docs and use decisions already made in the conversation.

If `grilling` is available, consult it for the interview. Otherwise ask focused questions directly, prioritizing answers that would change the design. Do not require a particular skill-loading tool or block because an optional skill is missing.

Use `domain-modeling` when terminology or architectural decisions need to be recorded. If unavailable, update the existing glossary or ADR format directly. Capture decisions when resolved, distinguish proposals from accepted decisions, and do not ask for confirmation of choices already approved.
